# ecommerce-sql-customer-analysis
Business driven e-commerce customer and revenue analysis using SQL

## Analytical Focus
This project focuses on revenue analysis, customer value identification, and churn risk detection using SQL-based aggregation and filtering techniques.

## Key Metrics Used
- Total Revenue
- Purchase Frequency
- Customer Spend
- Recency (Days since last order)

## Business Interpretation
The queries are designed to support decision-making related to customer retention, regional performance, and revenue optimization.
